<h1><div align="center">map editor</div></h1>
<div align="center">
    <p>an <i>arguably</i> better editor ui for map view</p>
    <img src="./.assets/editor.jpg" alt="Editor UI" width="100%"/>
</div>

<h3><div align="center">description</div></h3>

<p>
    <div align="center">
    introduces a collapsible overlay over the chat log allowing selection of the various different tiles and objects that can be placed on the map, and hides the default clunky one.
    </div>
</p>

<h3><div align="center">usage</div></h3>
<p><div align="center">enter a map room with admin access, the editor will open automatically!</div></p>

<h3><div align="center">installation</div></h3>
<div align="center"><sup>(pick from whichever git host you prefer)</sup></div>

```js
// GitHub
javascript:(()=>{import("https://tenjou-no-kitsune.github.io/cfme/main.js")})();
// GitGud
javascript:(()=>{import("https://tengoku.gitgud.site/cfme/main.js")})();
```

<h3><div align="center">uninstallation</div></h3>
<p><div align="center">just run <b>/cfme unload</b> in the chat</div></p>
